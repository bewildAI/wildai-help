Grok订阅教程：如何用WildAI升级马斯克全家桶？套餐与开通步骤

WildAI 帮助中心 · 更新于 2026-10-20 · 约 5 分钟阅读

马斯克全家桶是什么？包含Grok、Cursor和X吗？

这里的“马斯克全家桶”指整合 Grok、Cursor 和 X 权益的 The X Subscription。官方说明，Grok 与 Cursor 共享每周包含的用量池；X 权益需要关联个人 X 账号，具体内容随套餐变化。来源：X 官方订阅说明↗（新窗口打开）

因此，选择套餐时，要同时考虑自己使用 AI、编程和 X 的需求。尤其要区分新整合订阅与旧版 SuperGrok、X Premium 订阅，不能仅凭名字相似就认定权益一致。

WildAI 是本文介绍的第三方订阅入口。官方价格页明确表示未授权第三方销售，并提示此类订阅存在安全及账号停用风险。使用前应了解这一点，不能把第三方服务称为官方授权渠道。来源：官方价格页购买渠道说明↗（新窗口打开）

选择时，可以先确定自己的预算和使用频率，再比较额度。偶尔使用与每天大量调用 AI 的需求不同，不必仅因为“全家桶”三个字就选择最高档。

如果你特别在意 X 权益：官方说明 Plus 包含认证标记、创作者工具和较少广告；Premium、Super、Ultra 对应完整的 X Premium+ 权益，需连接个人 X 账号。具体生效情况仍以账号页面为准。

使用WildAI升级前，需要准备什么？

准备好能够正常登录的 Grok 账号，并确认这是你希望升级的账号。如果浏览器里登录了多个账号，先核对当前账号信息，避免给错误账号开通。

如何使用WildAI开通？按截图完成以下步骤

第一步：打开WildAI，选择Grok

进入 WildAI订阅页面↗（新窗口打开），在「新订阅」页面找到 Grok 卡片，选择相应入口继续。

这页同时列出了其他产品，本文要操作的是标有「Plus / Premium / Super / Ultra」的 Grok 卡片。

图1：Grok订阅入口。图片中的价格仅作界面示意，以实际订单为准。

第二步：选择Plus、Premium、Super或Ultra

进入「选择您的 Grok 方案」页面后，点击需要的套餐，再点击「下一步」。

如果还不确定选哪一档，先返回查看套餐说明。已有付费订阅的用户，也应在付款前确认这是续订、升级还是迁移到新订阅，避免误把不同操作当成同一件事。

图2：选择套餐后继续。

第三步：登录自己的Grok账号

页面会提示前往 Grok 登录。点击「开启」，进入 Grok网站↗（新窗口打开），完成登录后返回 WildAI。

此时再核对一次当前账号。后续提交的账号信息应与希望升级的账号一致。

图3：在Grok网站完成登录，然后返回。

第四步：按页面指引导出Grok Cookie

截图展示的方式是使用电脑端 Chrome 的 Cookie Editor 扩展：

  1. 按页面入口安装扩展，并确认扩展来源和申请的权限。

  2. 打开 grok.com，确认已登录需要升级的账号。

  3. 点击浏览器工具栏中的 Cookie Editor。

  4. 选择「Export → JSON」，复制导出的完整内容。

这一步复制的是账号会话数据，不是普通网址。不要在聊天窗口中展示它，也不要把包含实际凭证的操作截图公开。

图4：截图展示的Cookie导出流程。

第五步：粘贴完整JSON，完成页面校验

返回 WildAI 的「贴上您的 Grok Cookie」页面，将复制的完整 JSON 数组粘贴到输入框。

页面说明会检查格式是否符合要求。不要只复制其中一项，也不要手动删掉括号或引号。如果出现格式提示，先核对是否完整复制。

格式校验通过不等于订阅已经开通。 后续仍应按实际页面核对订单和完成必要操作。

图5：粘贴内容后，根据页面提示继续。

第六步：核对订单，并检查权益是否生效

以上截图到 Cookie 输入页面结束，没有展示付款与成功页面。进入后续流程时，应以实际界面为准，重点核对套餐、周期、金额及升级账号。

完成后，返回 Grok 的订阅或账单页面，检查套餐名称和有效期。需要使用 X 或 Cursor 权益时，再核对相关账号是否正确关联。不要仅凭第三方订单显示完成，就认定所有产品权益都已生效。

如果状态异常，保留订单号、支付记录和错误提示，联系客服处理；公开交流时隐藏账号凭证。

Grok订阅常见问题

可以用微信或支付宝支付吗？

Wildai支持微信和信用卡支付

有旧版SuperGrok或X Premium，还需要重新购买吗？

先确认现有订阅状态及迁移方式。官方说明切换到整合订阅是可选的，旧计划在主动变更或取消前可以继续保留；迁移具有不可逆性。涉及旧订单退款时，还需区分购买渠道，不能直接套用到所有第三方订单。来源：官方迁移说明↗（新窗口打开）

升级成功后，为什么X或Cursor仍没有显示权益？

先核对登录账号、账号关联状态和订阅记录，再检查购买的具体套餐。Grok账号的订阅状态与另一个产品的登录状态需要分别确认，不能只看其中一页。

Cookie格式校验失败怎么办？

按照页面要求重新检查导出格式，确认复制的是完整 JSON 数组。如果格式正确仍然失败，保留错误提示并联系平台客服支持。

订阅失败是否可以退款？

截图中出现了“订阅失败全额退款”的平台说明，订阅失败即可找客服进行退款
