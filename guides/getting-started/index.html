第一次使用 WildAI？从这里开始

WildAI 帮助中心编辑组 · 更新于 2026-10-13 · 约 3 分钟阅读

先看结论

通过带邀请码 AIG 的入口进入 WildAI，选择 ChatGPT 或 Claude，确认新订阅或续费、套餐和订单金额，再按照订单页面提示完成操作。最后回到对应产品核验会员状态。

先准备好这些信息

准备可以正常登录的 ChatGPT 或 Claude 账号，并确认自己使用的登录方式。提前检查账号目前是否已有付费订阅、到期时间以及需要新订阅还是续费。帮助中心不会收集你的密码、验证码或支付信息。

打开 WildAI，找到订阅入口

通过本页的「前往 WildAI」进入官网，链接携带 code=AIG。在首页点击 Get Started（开始使用），进入订阅页。官网可能根据语言显示不同的按钮文字。

选对产品，也选对订单类型

订阅页分别列出 ChatGPT 和 Claude。先选择产品，再查看套餐选项。页面有 New subscription（新订阅）与 Renew for subscribed account（已订阅账号续费）入口；已有会员时，请先核对续费说明再下单。

以订单页为准完成操作

阅读该套餐当前的订阅说明、账号要求、最终费用和售后规则。登录后的支付与交付界面可能更新，请按官网订单页的实时提示操作，不要照搬旧教程中的按钮或价格。

订阅后回到原产品核验

使用下单对应的账号登录 ChatGPT 或 Claude，查看当前计划或订阅页面。将套餐、账号与订单逐项核对；出现不一致时，保留订单信息联系 WildAI 客服。
