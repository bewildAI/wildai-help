WildAI 开通 Claude 选哪个套餐？Pro、Max、Ultra 区别与价格（2026）

更新时间：2026 年 11 月 12 日 · 阅读约 5 分钟

2026 年 10 月底，Anthropic 调整了 Claude 的个人套餐：原来的 Max 5x 改名叫 Max，Max 20x 改名叫 Ultra，价格没变。现在付费套餐只剩 Pro、Max、Ultra 三档。这篇文章帮你一次搞清楚区别，以及自己该买哪个。

一句话结论

  • 轻度使用、偏日常对话： 选 Pro
  • 每天重度用、经常用 Claude Code 写代码、想长期用 Fable： 选 Max
  • 全天候跑长任务、不想被 5 小时限制打断： 选 Ultra

重点解读：容易搞错的几件事

1. "5 倍""10 倍"指的是什么？

Claude 的用量有两层限制：每 5 小时一个窗口，和每周一个总额度。Max 两层都是 Pro 的 5 倍；Ultra 是周额度 10 倍，而且认证账号不再受 5 小时窗口限制。

换算一下会发现，三档的"每 1 倍 Pro 用量"都是 $20/月。贵的套餐并不更划算，只是额度更多。 用不完的话，就是白花钱。

2. Max 20x 去哪了？

就是现在的 Ultra。原来订阅 Max 20x 的用户已经自动转为 Ultra，价格不变，不需要任何操作。

3. Fable 5.2 的额度怎么算？

Fable 是 Claude 最强的模型。在 Max 和 Ultra 上，Fable 最多能用到周额度的一半，而且比其他模型更吃额度。Pro 上的 Fable 不占套餐额度，按 API 价格单独扣费。

💡 限时福利： Fable 5.2 发布周（截至北京时间 11 月 17 日 15:59），Pro 用户也可以免费用 Fable，最多占周额度 50%。详细说明看《WildAI 能开通 Claude Fable 5.2 吗？》。

4. Claude Code 和网页版共用额度吗？

共用。用订阅账号登录 Claude Code 时，写代码和在网页、App 里聊天扣的是同一份额度。重度用 Claude Code 的程序员，Pro 很容易不够用。
