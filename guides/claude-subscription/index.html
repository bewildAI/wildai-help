什么是 WildAI？

WildAI↗（新窗口打开） 是一个协助用户升级 AI 订阅服务的代订平台。通过 WildAI，你可以升级 ChatGPT（Go / Plus / Pro）、Claude（Pro / Max）、Gemini（Pro / Ultra）、Claude API、Codex Credit 等多种服务，并使用微信、支付宝等本地付款方式完成支付，不需要海外信用卡。

与“共享账号”不同，WildAI 升级的是你自己原有的 Claude 账号。升级后，你照常使用自己的账号登录 claude.ai，所有对话记录和 Project 都会保留。

💡 省钱提醒：在最后结账时输入邀请码 AIG，可以直接抵扣 1 美元。记得在付款前填好。

升级前的准备

开始之前，请确认你已经准备好：

  • 一个已经注册好的 claude.ai 账号，免费账号即可，升级后会变成 Pro / Max。

  • 电脑版 Chrome 浏览器，用于安装 Cookie-Editor 扩展。

  • 微信或支付宝，用于付款。

  • 邀请码 AIG，可抵扣 1 美元。

步骤一：选择 Claude 套餐

进入 WildAI↗（新窗口打开） 的“新订阅”页面后，你会看到多个服务选项：ChatGPT、Claude、Gemini、Claude API、Codex Credit。请点击 Claude 卡片（Pro / Max+，$24.99/月起）。

图 1 选择 Claude 服务

接着进入“步骤 1：选择您想要订阅的 Claude 套餐”。你会看到三个等级：

图 2 Claude 单月套餐与价格

如果想要一次订阅多个月，可以切换上方的“2 个月”“3 个月”标签页。系统会以“分月自动到账”的方式处理，价格也会随之调整，例如 Pro 2 个月为 $45.69。

图 3 Claude 多月套餐：截图为 2 个月选项

选好套餐后，点击“下一步”。

步骤二：网络环境风险检测

为了检查订阅时的网络环境，WildAI 会进行一次“网络环境风险检测”

图 4 网络环境风险检测结果示例

当结果显示绿色的“低风险 · 网络环境正常”时，表示通过了 WildAI 的这项检测，可以点击“继续订阅”。

⚠️ 若检测出现红色或高风险项目，例如代理与时区不一致，建议检查网络设置后再点击“重新检测”。此结果仅供参考，不保证与 Claude 官方的判断完全一致，也不代表账号不会受到限制。

步骤三：安装 Cookie-Editor 并导出 Cookie

这是整个流程最关键的一步。WildAI 需要你 claude.ai 账号的 Cookie 来代为完成升级。按照平台的说明，Cookie 仅用于本次订阅。

3-1 安装 Cookie-Editor 扩展

在“步骤 3：使用 Chrome 扩展获取 claude.ai 的 Cookie”页面，点击“在 Chrome 安装此扩展”，会跳转到 Chrome 应用商店的 Cookie-Editor 页面。

图 5 从 WildAI 页面进入扩展安装入口

在 Chrome 应用商店点击“添加至 Chrome”，完成安装。

图 6 Cookie-Editor 扩展页面（截图为已安装状态）

3-2 打开 claude.ai 并授权

  1. 打开一个新标签页，前往 claude.ai，确认已经登录。

  2. 点击浏览器右上角的 Cookie-Editor 扩展图标。

  3. 如果出现“You do not have the permission required to read the cookies for this page”，请点击“This site”，即仅授权当前网站。

图 7 点击 This site，仅授权当前网站

接着，Chrome 会弹出“Cookie-Editor has requested additional permissions”，点击“Allow”允许。

图 8 确认扩展申请的 Claude 网站权限

3-3 将 Cookie 导出为 JSON

  1. 再次打开 Cookie-Editor，此时会列出 claude.ai 的 Cookie。

  2. 点击右下角的“Export（导出）”按钮。

  3. 在“Export As”菜单中选择“JSON”。

图 9 先点击右下角的 Export 按钮

图 10 再选择 JSON 导出格式

此时，Cookie 的 JSON 内容已经自动复制到剪贴板。返回 WildAI 页面，点击“已复制 Cookie，下一步”。

步骤四：粘贴 Cookie 并完成付款

4-1 粘贴 Cookie JSON

在“步骤 4：将复制的 Claude Cookie 粘贴到下方输入框中”页面，把刚才复制的 JSON 粘贴到橙色输入框中。系统会自动校验 Cookie 格式是否符合要求；导出的 Cookie JSON 应为一个数组。

图 11 将 Cookie JSON 粘贴到输入框

4-2 阅读并同意规则

粘贴后会弹出“Claude 封号与退款说明”，请务必仔细阅读。

图 12 阅读 Claude 封号与退款说明后确认

4-3 扫码付款

进入付款页面后，选择支付方式，例如微信支付，用手机扫描页面上的二维码完成付款。付款完成后，点击“已完成支付”。

图 13 选择支付方式并完成扫码付款

升级完成

付款成功后，你会看到绿色勾选图标和“您的账户已成功升级”提示。点击“完成”即可。

图 14 账户升级成功提示

升级可能存在几分钟的同步延迟。如果尚未生效，可以重新登录 Claude 或刷新页面，再检查账号是否已显示为 Pro 或 Max 套餐。

常见问题 FAQ

Q1：WildAI 升级的是我自己的 Claude 账号吗？

是的。WildAI 升级的是你原有的 claude.ai 账号，不是共享账号。升级后，你照常使用自己的账号登录，对话记录与 Project 都会保留。

Q2：为什么需要提供 Cookie？

Cookie 中可能包含 claude.ai 的登录会话凭证。WildAI 通过这些信息识别账号并代为完成升级。按照平台的说明，Cookie 仅用于本次订阅。

Q3：付款后多久生效？

通常即时或数分钟内生效。若没有立即显示，可以重新登录或刷新 claude.ai 页面。持续未生效时，应核对订单状态并联系平台客服。

Q4：可以使用哪些付款方式？

支持微信本地付款方式，不需要海外信用卡。具体可用方式以付款页面为准。

Q5：邀请码在哪里填写？优惠多少？

在结账付款前的页面填写邀请码 AIG，可直接抵扣 1 美元。

Q6：账单显示 bewild.ai 是什么？

这是本教程所示付款流程中的 WildAI 扣款名称。请结合订单号、金额和收款信息核对。

Q7：会不会被封号？

存在风险。Claude 会检查使用地区及其他账号信息，WildAI 的网络检测不能保证账号安全。平台对因地区限制导致的封号不承担退款责任，请在订阅前阅读相关规则并自行评估。
